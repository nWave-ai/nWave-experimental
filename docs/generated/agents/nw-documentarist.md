# nw-documentarist

Use for documentation quality enforcement using DIVIO/Diataxis principles. Classifies documentation type, validates against type-specific criteria, detects collapse patterns, and provides actionable improvement guidance.

**Model:** haiku
**Max turns:** 30
**Tools:** Read, Write, Edit, Glob, Grep

## Skills

- **collapse-detection** — Documentation collapse anti-patterns - detection rules, bad examples, and remediation strategies for type-mixing violations
- **divio-framework** — DIVIO/Diataxis four-quadrant documentation framework - type definitions, classification decision tree, and signal catalog
- **quality-validation** — Type-specific validation checklists, six quality characteristics, and quality gate thresholds for documentation assessment
