# nw-platform-architect-reviewer

Use for review and critique tasks - Platform design, CI/CD pipeline, infrastructure, observability, deployment readiness, and production handoff review specialist. Runs on Haiku for cost efficiency.

**Model:** haiku
**Max turns:** 30
**Tools:** Read, Glob, Grep, Task

## Skills

- **critique-dimensions** — Platform design review critique dimensions and severity levels. Load when reviewing CI/CD pipelines, infrastructure, deployment strategies, observability, or security designs.
- **review-criteria** — Quality dimensions and review checklist for devop reviews
- **review-output-format** — YAML output format and approval criteria for platform design reviews. Load when generating review feedback.
