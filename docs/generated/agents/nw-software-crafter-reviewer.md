# nw-software-crafter-reviewer

Use for review and critique tasks - Code quality and implementation review specialist. Runs on Haiku for cost efficiency.

**Model:** haiku
**Max turns:** 30
**Tools:** Read, Glob, Grep, Task

## Skills

- **review-dimensions** — Reviewer critique dimensions for peer review - implementation bias detection, test quality validation, completeness checks, and priority validation
- **tdd-review-enforcement** — Test design mandate enforcement, test budget validation, 5-phase TDD validation, and external validity checks for the software crafter reviewer
