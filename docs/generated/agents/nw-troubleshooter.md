# nw-troubleshooter

Use for investigating system failures, recurring issues, unexpected behaviors, or complex bugs requiring systematic root cause analysis with evidence-based investigation.

**Model:** inherit
**Max turns:** 30
**Tools:** Read, Write, Edit, Glob, Grep, Bash, Task, WebSearch, WebFetch

## Skills

- **five-whys-methodology** — Toyota 5 Whys methodology with multi-causal branching, evidence requirements, and validation techniques
- **investigation-techniques** — Evidence collection methods, problem categorization, analysis techniques, and solution design patterns
- **post-mortem-framework** — Blameless post-mortem structure, incident timeline reconstruction, response evaluation, and organizational learning
