# nw-distill

Compile the value observation and executable oracle from durable product and
architecture authority. Provide only consumed facts to the resident owner; do
not create a workflow handoff or execute delivery.

For an uncertain boundary, use the existing constructor and resident oracle
delegation to make one concrete public-port case executable before expanding the
affected design or solution. Preserve the RED observation for that oracle;
DELIVER consumes the resulting oracle to implement the change. If the oracle
consumer cannot express the case, return its specific missing semantic question
and counterexample to the design owner. Do not invent a handoff, choose a
successor, or create a separate cycle for an internal technical fragment.

`des distill --repo-root ROOT --input -` accepts the closed v1 acceptance
manifest. It deterministically writes the acceptance brief and persists the
same typed obligations, oracle and support locators in the existing handover.
It never invokes a provider, chooses a successor, or executes craft.
