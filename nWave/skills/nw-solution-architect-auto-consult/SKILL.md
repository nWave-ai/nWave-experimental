# Auto Architecture Consult

**Kind**: PROCEDURE. **Job**: close one bounded Auto architecture consult.
**Trigger**: exact AUTO-ARCHITECTURE-CONSULT envelope, optionally with its
verbatim repair field. Malformed Auto is BLOCKED; non-Auto DESIGN uses full DESIGN.

## Deterministic sequence

1. **Validate envelope** — accept exact subject, absolute root and resolved
   route; repair accepts only producer byte-for-byte BLOCKED stdout. Gate:
   malformed returns `ARCHITECTURE-BLOCKED`.
2. **Load lenses** — load algebra before public constructors/observations/laws,
   certainty for invalid-state/preservation and triggered stress. Lenses/formal
   runs are not fact calls; `no skill preload` excludes unrelated eager context,
   never a triggered lens. Gate: every applicable lens loaded.
3. **Gather facts** — use ≤6 `des code-fact`/Read/Grep calls; by call four
   reuse/write brief/ADR. Ground target rows in symbols: Target is repo-relative
   path, Decision `EXTEND` or `CREATE_NEW`. Gate: unresolved fact/readiness/
   anchor returns BLOCKED.
4. **Edit safely** — re-read the exact edit zone using a short stable anchor;
   after mismatch re-read and make exactly one fresh second edit attempt. Gate:
   no stale-context retry or retry instruction in BLOCKED HOW.
5. **Formal proof** — only for a separately selected proof obligation; formal
   procedure owns availability. Gate: unavailable tooling affects only that proof.
6. **Verify citations** — batch files; `path:line` uses Read, symbol-only uses
   `des code-fact query.atoms-in-file`, callers/reads resolve from repo root.
   Enumerate `fact -> file -> outcome`, then record `Citations verified: N/N
   (line-checked: k, symbol-checked: m)` before COVERED. Gate: mismatch,
   uncheckable or incomplete returns BLOCKED.
7. **Seal authority** — apply `nw-design`'s projection, risk, admission and
   obligations in the same brief/ADR; human-only choice is `QUESTION/NEEDS_INPUT`.
   Return existing `ARCHITECTURE-BLOCKED` WHAT/WHY/HOW; add no artifact. Read back the
   target permanent authority after its final Write/Edit; derive the
   section-anchor from an actually present Markdown heading, never invent an
   anchor from a task name or summary. Gate: a missing path or heading returns
   `ARCHITECTURE-BLOCKED`; otherwise return exactly COVERED locator or BLOCKED
   WHAT/WHY/HOW.

## Composition

- `nw-algebraic-design-protocol` — public constructors, observations and laws.
- `nw-certainty-by-construction` — invalid-state and preservation claims.
- `nw-stress-analysis` — declared external/recovery stressors.
- `nw-solution-architect-formal-verification` — a triggered formal claim.

## Verification

- [ ] One authority path and anchor were written/reused.
- [ ] At most six repository fact calls; lens/proof work recorded separately.
- [ ] Every citation count is derived and verified before COVERED.
- [ ] Terminal is one exact `ARCHITECTURE-COVERED` or `ARCHITECTURE-BLOCKED` line.
